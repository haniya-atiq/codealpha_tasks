## 🎮 Task 2: Hangman Game

### 📝 Description
A classic word-guessing game where players try to uncover a hidden word letter by letter before running out of attempts.

### ⚙️ How It Works
1. Random word is selected from word bank
2. Word is displayed as underscores
3. Player guesses one letter at a time
4. Correct guesses reveal the letter(s)
5. Wrong guesses reduce remaining attempts
6. Game ends when word is guessed or attempts run out

### 🎯 Features
- ✅ Random word selection
- ✅ 6 maximum incorrect guesses
- ✅ Letter tracking system
- ✅ Input validation
- ✅ Win/Loss detection
- ✅ Visual word progress

### 📁 File: `Hangman Game.py`

## 📊 Task 3: Stock Portfolio Tracker

### 📝 Description
A portfolio management tool that calculates and tracks stock investments, showing total portfolio value with export capabilities.

### ⚙️ How It Works
1. User selects stocks from available list
2. Enters quantity for each stock
3. System calculates individual and total values
4. Displays portfolio summary
5. Option to save to file
